# A股热力图（大盘云图 · 样式研究）

对 dapanyuntu.com 热力图画布的样式研究复刻。渲染参数（二分 treemap 布局、归一化 score 色阶、四级自适应标签、视图缩放平移、标题带涨跌家数）来自对其构建产物的逆向分析，**代码为独立重写**；已接入实时行情（自选免费源组合，见下）。

**本项目完全自包含**：不依赖 `heatmap`、`dapanyuntu-study` 或任何其他目录，删掉别的文件夹不影响本项目。

## 使用

**双击 `index.html` 即可**（file:// 直开，无构建无框架）。交易时段每 10s 自动刷新行情；非交易时段显示最新收盘快照。

## 文件

| 文件 | 说明 |
|---|---|
| `index.html` / `style.css` / `app.js` | 页面骨架 / 深色主题样式 / 全部渲染与交互逻辑（约 1300 行，无框架） |
| `data/treemap.js` | 渲染数据（`window.TREEMAP_DATA` 赋值，script 标签加载，file:// 可用；含 `.markets` 多指数子树） |
| `data/*.json` | 原始 fixture（**全 API 抓取，无 OSS 快照**）：`live-treemap.json` 主树 + `live-treemap-{hs300,zza500,etf,hk}.json` 四棵市场树 + `live-quotes{,-etf,-hk}.json` 抓取时点行情（构建时按代码合并进所有树） |
| `make_data.py` | JSON → `data/treemap.js` 转换器（主树 + 多指数树挂 `markets`，自动合并 live-quotes.json 的盘中行情） |
| `refresh_fixtures.sh` | 重抓最新数据（重试 + JSON 校验循环，绕 Cloudflare 闪断） |

## 更新数据

```bash
bash refresh_fixtures.sh  # 抓最新 JSON 到 data/（5 棵树 + 3 份行情）
python3 make_data.py      # 重新生成 data/treemap.js（主树 + markets 子树）
```

数据边界：抓来的数据仅限本地开发/学习，不要连数据带站名对外发布。

## 上 GitHub（Pages 托管 + 每日自动更新）

**线上地址：https://dabenliu.github.io/ashare-heatmap/** （工作日 17:00 自动换新数据）

1. 新建 **public** 仓库，推整个目录（`backup-*/` 已被 .gitignore 排除）
2. Settings → Pages → Source 选分支根目录 → 得到 `https://用户名.github.io/仓库名/`
3. `.github/workflows/update-data.yml` 已内置：**工作日北京时间 17:00**（UTC 09:00）自动跑 `refresh_fixtures.sh` + `make_data.py`，数据有变化才提交回仓库，Pages 随之重新发布；Actions 页有手动触发按钮
4. 更新在 GitHub 服务器上执行，本地误删/误改不影响线上；本地恢复 = `git clone`
5. 注意：GitHub 数据中心 IP 理论上可能被 Cloudflare 拦得更凶，某天抓取失败时会保留旧数据不提交（页面不坏）；Actions 定时任务在仓库 60 天无任何活动时会被停用——本任务每次自动提交都算活动，正常会一直活着

## 已实现（M1）

- 三层嵌套二分 treemap：板块 → 子板块 → 个股，零负值钳 1。分割线宽度可调（`app.js` 顶部 `GAP_BOARD/GAP_SUB/GAP_STOCK_BIG/GAP_STOCK_SMALL`，当前 0.5/0.5/0.25/0.125（原站 2/2/1/0.5，再减半请直接改常量；设 0 无缝））
- 标题带：`名字 · 涨N 跌M · ±x.xx%`（市值加权涨跌幅），宽度不足从右往左舍弃；板块带带「›」钻取箭头
- 个股四级标签（阈值随缩放）：大块居中 2~3 行（名字/涨跌幅/价格）、中块两行、小块单行、微块仅名；`measureText` 二分截断 + 缩字号 + clip 兜底
- 色阶（2026-11-10 重做）：**归一化 score 映射**——score = 真实涨跌幅 ÷ 该标的涨跌幅限制（主板 10% / 主板 ST 5%、创业板与科创板 20%（ST 不减半）、北交所 30%），±1 统一代表涨/跌停，跨板块视觉公平（创业板 +10% 是半板浅红，主板 +10% 是涨停深红）；再经 |score|^0.65 幂矫正放大中间小涨跌的档位区分（`app.js` 顶部 `POW_EXP` 可调）。20 档色带沿用 `BAND_UP/BAND_DN`（暗底调色，只换色不改逻辑就改表）。图例为 score 轴离散档色带（跌停 ← 平盘 → 涨停，半板刻度）；方块文字仍显示真实涨跌幅。旧版 P80 自适应量程与 `AUTO_RANGE` 已随 score 方案移除
- 视图：滚轮缩放 1~3 倍（光标锚定）、拖拽平移（钳边不露底）、双指捏合/移动端点按
- 交互：悬停高亮、单击标题聚焦板块（220ms 区分双击）、双击个股开雪球、Esc 复位（一下收抽屉 / 两下复位视图）、面积口径切换（流通市值/总市值/成交额）
- **抽屉（2026-11-10 定稿：推挤式共享窗口）**：body flex 行，抽屉 232px 宽度动画，画布 `flex:1` 占剩余宽度、随开合重排（共享窗口，非浮层）。桌面默认展开、鼠标移入画布自动收；**触屏/窄屏默认收起**——从屏幕左缘向右滑唤出，头部 ✕ 或点画布任意处收起。抽屉内从上到下：品牌（✕）→ 市场切换竖排行（10 市场，带实时报价）→ 面积口径 seg → 弹性空白 → 统计表（涨跌家数 + 成交额/较昨日，圆角分割线网格）→ 图例 → 更新时间。抽屉中部弹性区放**板块资金流双列排行**（净流入/净流出 Top20，东财行业板块口径，金额颜色随主力净占比走 score 色卡）。钩子：`window.onLeftEdgeChange = (open) => {}`、`body.drawer-open` 类
- **检视器（dapanyuntu n8 1:1）**：三层结构——①深色个股头部条（背景=该股标题带色，名称 + 东财 108px 分时迷你图 + 价格/市值/涨跌幅）②白底日K区（新浪 `image.sinajs.cn/newchart/daily/n/` GIF，宽 88%，随交易日更新）③浅灰成分列表区（板块统计 + 七键排序按钮组平铺 + 行网格 [名称|迷你图56px|价格64px|涨跌幅80px]，悬停股 sticky 钉顶）。容器样式照抄原站（slate-600/80 边框、#0f1319/96 底、backdrop-blur、0 22px 72px 阴影）。排序：按钮直点或 S/Shift+S 循环；↑↓/J/K 滚动；**G 固定**（固定时头部条显示「已固定·Esc解除」徽标，单击个股不再误触发固定），Esc 解除。图源：行内迷你图=东财 RJY（mix-blend screen），日K=新浪（均 no-referrer）。**触屏设备（2026-11-10）**：点个股=固定显示、点其他个股=切换、点画布空白或标题带=关闭，头部另有 ✕ 按钮（仅 `pointer:coarse` 显示，桌面视觉与交互不变）
- DPR 适配（1~2）、ResizeObserver 自适应

## M2 实时行情（2026-11-09）

- **组合拳数据源**（默认「全部」页每轮 4 个并行请求 ~200ms，按当前市场裁剪，全部浏览器直连 CORS `*`，实测验证）：
  - `gateway.jrj.com` POST ×1：沪深 5,213 只 现价+涨跌幅（`var` 是小数，×100 转百分比）
  - `qt.gtimg.cn` GET ×3：北交所 343 只（`s_bj` 前缀，GBK 解码），现价+涨跌幅+**成交额**
- **交易时段每 10s 轮询**（9:15–11:35 / 12:55–15:10，周末自动停），行情更新**不重算布局**（面积=构建时市值权重）：只刷个股色/标签、板块聚合带、涨跌家数
- 状态栏三态：`实时 HH:MM:SS` / `实时中断(N)，数据 HH:MM:SS`（连续失败保留旧数据）/ `快照 <时间>`（启动首帧）
- **成交额摘要（统计表第二行）**：实时走同花顺 fuyao 接口（`dq.10jqka.com.cn`，CORS `*`，原站摘要条同源；header 直出当日/昨日/变动/预测全天），失败自动回退抓取时点 summary（标注「·抓取时点」）
- 所有 fetch 带 8s 超时；沪深覆盖 5,213/5,223（99.8%），缺的 10 只保持静态值
- 口径说明：涨跌幅以实时源为准；沪深成交额为快照值（jrj 不提供；如需实时可扩腾讯批量但 =38 请求/轮，不推荐）
- 顶栏市场切换条：`全部 | 上证 | 深证 | 沪深300 | 中证A500 | 创业板 | 科创板 | 北交所 | ETF | 港股`，每片带对应指数实时报价（全部=中证全指、深证=深证综指），**点击切换云图市场**（选中高亮）。原「逆向参数重写」副标题已删，操作提示在悬浮 title 上
- **多指数云图（2026-11-10）**：两类市场——① rule 型（全部/上证/深证/创业板/科创板/北交所）：纯前端按 exchange/代码段过滤全 A 树；② tree 型（沪深300/中证A500/ETF/港股）：`refresh_fixtures.sh` 抓独立树挂到 `DATA.markets`，切换时整棵重排。沪深300/中证A500 为成分指数云图（原站 API `market=hs300|zza500`；中证500/中证1000 原站自身未提供，API 返回空树）；ETF/港股为独立市场云图。fixture 缺失时对应标签自动隐藏；腾讯指数缺价时用树内 `summary.indexChangePct` 兜底
- **完全去快照（2026-11-10）**：`snapshot-*.json`（OSS 快照）已删除，主树/四棵市场树全部来自站点 API 抓取，抓不到即报错不再兜底。ETF/港股盘内行情实时化：腾讯批量（ETF `s_sh/s_sz` 简版 f3/f5/f7、港股 `hk` 全量 f3/f4/f37 涨跌现算，150 码/批），**仅在对应页激活时拉取**（ETF 12 批 / 港股 19 批，jrj 在这两页跳过）；ETF/港股成交额摘要=腾讯逐股加总（实时），沪深300/中证A500 成交额=树 summary（标注「·抓取时点」）。切换市场立即补拉一轮行情
- **面积口径结论（2026-11-10 REA 实测 52etf.site）**：52etf 的面积同样固定——首屏一次性 `_payload.json`（Nuxt 构建载荷）携带整树市值权重，8s 轮询只拉 jrj 个股价/涨跌幅 + 腾讯指数 + 同花顺涨跌分布/成交额，**不含任何面积/市值字段**。本项目与其同构：面积=构建时 API 抓取的市值权重，行情实时。面积实时化需要每轮整树重排（三家站点都没这么做）
- **性能不变（2026-11-10 多指数版）**：轮询仍 10s/轮、仍 4 个并行请求（jrj ×1 + 北交所腾讯批量 + 同花顺摘要 + 指数腾讯批量），行情匹配只是多遍历几棵树的码表；布局只对当前市场计算，切换市场 ≈ 34–95ms（含两次 rAF）；`treemap.js` 1.2MB → 2.3MB（一次性解析，渲染路径不变）
- 港股兜底：东财分时图床与新浪日K均无港股路径 → 检视器对 `.HK` 代码不渲染对应图片；双击仍开雪球（`S/HK01398` 格式）
- 腾讯接口坑（已兜）：`s_` 前缀对指数不稳定——有时返回简版（涨跌幅=f5）有时返回全量（无下划线键 `v_sh000001`，字段位也与股票不同）→ 解析同时兼容两种键格式，全量格式用 现价/昨收 现算涨跌幅
- 轮询开关/节奏：`app.js` 顶部 `LIVE.intervalMs`；数据源 URL 也在 LIVE 区块集中放置
